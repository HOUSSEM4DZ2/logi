# Simple HTML + JavaScript Version

This is a simplified version of the test application that requires **NO server, NO build process, and NO installation**.

## Files

- **simple-app.html** - Main HTML file (open this in your browser)
- **app-data.js** - Test questions and data
- **app-logic.js** - Application logic and rendering

## How to Use

1. Simply open `simple-app.html` in any modern web browser (Chrome, Firefox, Edge, Safari)
2. No installation or server required!
3. The app works completely offline after the first load (except for Tailwind CSS from CDN)

## Features

✅ All three tests (Logico-Matematiche, Pensiero Computazionale, Colloquio Motivazionale)
✅ Question randomization
✅ Progress tracking
✅ Results with detailed feedback
✅ Responsive design
✅ No dependencies to install

## Browser Compatibility

Works on all modern browsers:
- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)

## Notes

- The app uses Tailwind CSS from a CDN for styling
- All data is stored in browser memory (refreshing the page will reset progress)
- No backend or database required
- Perfect for local testing or simple deployment

## Customization

To modify the questions or tests, edit the `app-data.js` file. The structure is straightforward JavaScript objects.
